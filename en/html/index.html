Path finding and maze generation preview

library-brainmap is a header-only C++17 library for maze generation and path finding on a grid of "neurons". It ships with an interactive ImGui visualizer (guitest) that animates every search step.

Features

  • Path finders (brain::pathfinder_algo): A*, Dijkstra, Breadth-First Search, Depth-First Search, Greedy Best-First, Jump Point Search (JPS), Theta*, IDA*.
  • Flow Field (Dijkstra map, brain::flow_field): one search from the goal gives every cell its cost and next step.
  • Hierarchical Path Finding (brain::hpa_graph): cluster-based HPA* in exact and sparse modes.
  • Unidirectional and bidirectional search (brain::search_mode) for A*, Dijkstra and BFS.
  • Heuristics (brain::heuristic_method): Manhattan (default), Chebyshev, Octile, Hypot, Pythagorean and a custom one.
  • 13 maze generators (brain::maze_algorithm): Recursive Backtracker, Recursive Division, Prim, Kruskal, Eller, Hunt-and-Kill, Binary Tree, Sidewinder, Aldous-Broder, Wilson, Cellular Automata and others.
  • Custom step costs, 4/8-direction adjacency, optional diagonal corner cutting.
  • Save and load of the whole map.

Quick start

#include <brain_map.hpp>
using namespace brain;
int main()
{
brain_map map(51, 51);
// generate a maze
map.create_maze_ex(maze_algorithm::RecursiveBacktracer, {0, 0}, {50, 50});
// find a path
brain_map::result_site result;
bool found = map.find(pathfinder_algo::AStar, result, the_site {0, 0}, the_site {50, 50},
search_mode::UniDirectional);
if (found)
{
for (const the_site &p : result.connections)
; // p.x, p.y
}
}

Every call of find() starts from a clean search state, the walls (locks) are kept. You may also set the default algorithm once with brain::basic_brain_map::set_pathfinder().

Algorithms at a glance

Algorithm Optimal path Uses heuristic Typical use
A* yes (with an admissible heuristic) yes general purpose, fastest
Dijkstra yes no weighted maps without a good heuristic
BFS for equal step costs no simple, unweighted maps
DFS no no reachability, visualisation
Greedy Best-First no yes (only) very fast, "good enough" paths
Jump Point Search yes yes fast symmetry-breaking search on 8-direction grids
Theta* near-optimal (any-angle) yes smooth line-of-sight paths
IDA* yes yes iterative deepening with threshold pruning
Flow Field yes no many agents moving to one goal
HPA* (hpa_graph) exact or sparse yes repeated queries on large static maps

Note: the default heuristic is Manhattan: it is exact for the default step costs (orthogonal 1, diagonal 2), so A* returns the same cost as Dijkstra. The Pythagorean heuristic (squared distance) is fast but not admissible.

Hierarchical search (HPA*)

brain::hpa_graph cuts the map into clusters and searches a small abstract graph of cluster entrances. The graph is exact: costs equal Dijkstra's, but building it costs time and memory (every cell with a step into another cluster becomes a node), so it only pays off with many queries on a static map. Call build() again after the map changes.

brain::hpa_graph graph;
graph.build(map, 16); // cluster size 16, exact graph
graph.build(map, 32, true); // sparse graph: much faster to build, paths may be slightly longer
std::vector<brain::the_site> path;
graph.find({0, 0}, {1023, 1023}, path);
